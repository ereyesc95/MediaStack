1. WHAT THIS PROJECT IS
================================================================================

Modern reimplementation of **MediaBinger** — personal media library + player for:
  Music, Series, Movies, Books, Games, Universes, Files, Hobbies, Photos.

Reads files from a media root on disk, enriches via SQLite DB + provider APIs
(TMDb, IGDB, Google Books, MusicBrainz, Spotify, …),
serves a FastAPI API + React SPA.

Stack:
  - Backend: FastAPI + Uvicorn + SQLAlchemy + Pydantic Settings (Python 3.11+)
  - Frontend: React 19 + Vite 6 + TypeScript (no router library — custom route helpers)
  - DB: SQLite by default (data/mystack.db); optional MySQL import
  - Default API port: 8766
  - Default Vite port: 5174 (proxies /api → 8766)

7. ARCHITECTURE SUMMARY
================================================================================

MUSIC is artist-centric:
  Music/{Letter}/{Artist}/Albums|Singles|…   (preferred)
  Legacy: Music/{Letter}/{Artist}/Audio/{Category}/
  Also: Video/, Library/, Gallery/, Tours/

MOVIES / SERIES / BOOKS / GAMES use franchise/work folder names as the cross-module key.
  Same {Franchise} name → Related media (franchise index).
  Exceptions: .path, symlinks, DB aliases/overrides.
  Music artist ≠ movie franchise alone (biopic case) — subject/DB links.

Games path:
  Games/{Platform}/{Letter}/{Franchise}/{date}. {Game}/
  Catalog merges same franchise across platforms into one card.

Routing:
  Custom push*Route helpers + history; dual-parse legacy IDs/hashes AND human slugs.
  Shared /franchise/… URLs; entry module sets referrer for tab order (GAMES next to Overview
  when coming from Games hub) while About art follows artwork home.

Profiles / admin:
  Multi-profile; admin password gates write tools.
  NSFW unlock is a session flag from admin_nsfw_password.

Playback:
  Mini audio player; optional play-videos-locally (opens OS player vs browser).
  Media URLs: /api/media/file?path=…&v={mtime}

11. ARTWORK STEMS (MUSIC PLAYBACK — CRITICAL)
================================================================================

Code truth: backend/app/artwork_stems.py

Album / edition motion (exact stems):
  Cover - Animation   → cover_animation_url
  Cover - Canvas      → canvas_url
Static: Cover - Front / Back / Banner / Landscape / Portrait, Disc, …
Track: Cover - {Track Title}, Animation - {Track Title}, Canvas - {Track Title}

PRIORITY FOR NOW-PLAYING COVER:
  1. Track Animation - {title} if present
  2. Else track own still → suppress album Animation/Canvas
  3. Else album Cover - Animation over Front

Frontend gotcha — do not reintroduce:
  track.cover_animation_url ?? edition.cover_animation_url when track has own cover.
Video URL: use isVideoMediaUrl.ts  /\.(mp4|webm|mov|m4v)(?:$|[?#&])/i
  (extension may be followed by &v= cache-buster)
